# Parentheses
Source: https://developers.google.com/style/parentheses

Some readers ignore anything inside parentheses — don't put important information there if avoidable. Even for less important information, consider whether parentheses are truly necessary; often the sentence works as well (or better) using commas, dashes, semicolons, or separate sentences instead.

- If parentheses appear mid-sentence, keep the parenthetical thought short; otherwise use two sentences.
- If a full sentence is enclosed in parentheses, the period goes inside.
- Don't use parentheses to indicate optional plurals (see Plurals in parentheses).
- Write examples in a sentence rather than in parentheses: "Enter 228B22," not "Enter (228B22)."
