# Sources

Where the quality-checking facts in this skill come from. Open this when a person asks for the source of a practice, or wants to read further than a reference goes.

## How the facts were checked

The SimpleCov, Mutineer, Skunk, RubyCritic, and style-guide facts were checked against the installed gems and by runs on Ruby 4.0.3, including a run against a real `CHECKSUMS` section written by Bundler 4.0.10. Each reference lists its own sources at the end; this page collects them.
