# Active Voice

Source: https://developers.google.com/style/voice

Prefer active voice (subject performs the action) over passive voice (subject is acted upon) — with exceptions. Always make clear who's performing the action; passive voice easily omits the actor, leaving readers unsure who's responsible (reader, computer, server, end user, etc.).

- Recommended: "Send a query to the service. The server sends an acknowledgment."
- Not recommended: "The service is queried, and an acknowledgment is sent."

You can name the actor in passive voice with "by," but recasting to active is usually better.
- Recommended: "Send a query to the service. The server sends an acknowledgment."
- Not recommended: "The service is queried by you, and an acknowledgment is sent by the server."

See also: Active voice vs. passive voice in Google's Technical Writing One guide.

## Exceptions — passive voice is OK when
- Emphasizing the object over the action: "The file is saved."
- De-emphasizing the subject/actor: "Over 50 conflicts were found in the file." (not "You created over 50 conflicts in the file.")
- The actor's identity is irrelevant to the reader: "The database was purged in January."
