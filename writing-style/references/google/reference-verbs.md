# Verb Forms in Reference Documentation

Source: https://developers.google.com/style/reference-verbs

Phrase a method's main description in terms of what the method DOES (*gets*, *lists*, *creates*, *searches*) — not what the developer would use it to do (*get*, *list*, *create*, *search*). The distinction usually comes down to whether the initial verb ends in *-s*.

- Recommended: "tasks.insert: Creates a new task on the specified task list."
- Not recommended: "tasks.insert: Create a new task on the specified task list."

See the Google Cloud API design guide for more.
