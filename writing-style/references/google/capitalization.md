# Capitalization

Source: https://developers.google.com/style/capitalization

Follow standard American English capitalization rules, plus:

- Don't capitalize unnecessarily — think about why a word should be capitalized before doing so.
- Don't rely on capitalization alone to convey meaning (e.g., capitalized "Pod" vs. lowercase "pod" in Kubernetes — the distinction is lost on many readers).
- No all-uppercase except: official names, abbreviations always written in all-caps, or referring to code that uses all-caps.
- No camel case except: official names or referring to code that uses camel case.

See the word list for capitalization of specific words; see Product names for product name capitalization.

## Titles and headings
- Sentence case: capitalize only the first word, the first word after a colon in a subheading, and proper nouns/terms that are always capitalized.
- No period at the end of a title or heading, even with sentence case.

### References to titles and headings
- When referencing a title/heading from a document following this guide, use sentence case even if the original uses title case (so it matches when the source is eventually updated).
- When referencing a title/heading from a source that doesn't follow this guide, retain its original capitalization.

## Capitalization and colons
Lowercase the first word after a colon, UNLESS it's:
- A proper noun ("Open source software: Hadoop")
- A heading
- A quotation ("Arthurian wit: 'Bring me yon sworde'")
- Text following a label like "Caution" or "Note"

## Capitalization and figures
Sentence case for captions, labels, callouts, and other text in images/diagrams.

## Glossaries and indexes
- Lowercase glossary/index terms unless a proper noun or otherwise requires capitalization.
- Sentence case for glossary definitions.

## Hyphenated words
When a hyphenated word starts a sentence or heading, capitalize only the first element — unless a later element is a proper noun/adjective.

## Lists
Sentence case for all list items (see Capitalization and end punctuation).

## Tables
Sentence case for all table elements: contents, headings, labels, captions.

## Special capitalization style names
Don't use casing-style names (*camel case*, *snake case*) to describe a format — they don't localize well and aren't standardized. Instead, describe the actual requirement with an example.
- Recommended: "Enter the value for the `attribute` field in the format where there are no spaces between words and the first letter of each word is capitalized—for example, `AssertionAccount`."
