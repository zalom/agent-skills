# Ellipses
Source: https://developers.google.com/style/ellipses

Generally, don't use ellipses. An ellipsis is three contiguous periods indicating omitted, non-essential text. Don't use ellipses to indicate hesitation (called "suspension points" in that usage) — never used that way in this documentation.

## In your own writing
Omit unnecessary information and include all necessary information instead of using an ellipsis.

## In quoted text
OK to use an ellipsis to replace an omitted portion, EXCEPT at the beginning or end of the quoted text. If the omitted material spans one or more sentence boundaries, use four dots instead of three (the last one is a period).

## Formatting
Use three literal periods in a row (not the single-character ellipsis glyph), keeping all three dots together. Insert a space before and after the ellipsis, unless a punctuation mark immediately follows — in that case, no space after.

## UI elements
When describing UI elements that include an ellipsis (e.g., a menu item labeled "Save As…"), omit the ellipsis unless leaving it out would cause confusion.
